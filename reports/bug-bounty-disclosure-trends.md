# Bug Bounty Disclosure Trends

A useful vulnerability report is reproducible, scoped, and respectful of user data. Strong submissions explain the security boundary, impact, evidence, and a practical fix.

## Report structure

1. Summary and affected asset.
2. Preconditions and authorized test account.
3. Minimal reproduction steps.
4. Evidence that proves impact without exposing private data.
5. Clear severity reasoning and remediation guidance.
6. Timeline for communication and retest.

Only test within program scope. Never retain or publish data that is not yours.
