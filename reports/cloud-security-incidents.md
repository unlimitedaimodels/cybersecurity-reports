# Cloud Security Incidents

Cloud risk commonly comes from exposed storage, broad permissions, weak workload identity, and missing visibility between teams. Strong cloud security combines preventive policy with continuous detection.

## Practical controls

1. Inventory accounts, projects, regions, workloads, and public endpoints.
2. Use least privilege and short-lived workload credentials.
3. Block public storage by default and monitor policy changes.
4. Centralize audit logs and alert on privilege escalation.
5. Test recovery for identity, data, and infrastructure failure.
